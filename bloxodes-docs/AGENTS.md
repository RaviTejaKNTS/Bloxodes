# Bloxodes docs rules

Scope: `bloxodes-docs/`.

- Follow the rules at the top of [README.md](README.md): one topic per file, current state only, replace instead of append.
- When code, infrastructure, a schedule or a pipeline changes, update the owning file in the same PR.
- Bump `Last verified` only after checking the code or the live service.
- No plans, audits, logs or dated files here. Use your task's `tmp/` or Notion.
- Write in the style described in `.agents/skills/README.md`: plain, scannable, exact where it matters.
