# Our Sidebar Plan

## Direction

Move broad page-type navigation into the page header or top bar.

Use the left sidebar for contextual links that help people continue from the page they are already on.

## Top Navigation

Primary links only:

- Wiki
- Codes
- Catalogs
- Tools
- Stats

Other page types can be reached through search, footer links, related page links, and contextual sidebar sections.

## Left Sidebar Role

The left sidebar should answer: "What is useful from here?"

It should change by page type and page context instead of showing the same list everywhere.

## Page Examples

Game pages:

- Link to that game's codes, wiki, catalogs, events, checklist, quiz, tools, articles, and stats when available.

Catalog pages:

- Link to sibling catalogs, subcatalogs, related game pages, and useful catalog sections.

Stats pages:

- Link to genres, trending games, top games, and future watchlist areas.

## Right Sidebar Role

Keep the right sidebar visual, but make it less like a stack of content cards.

Use it for simple hooks that invite people into related pages.

Examples:

- Show the first quiz question with answer options.
- After a user selects an answer, show a "Continue on quiz page" action.
- Remember the first quiz answer and start from question 2 on the quiz page.
- Use similar lightweight previews for related tools, catalogs, and other pages.

## Open Questions

- Which top nav links are essential on mobile?
- What should the left sidebar show when there are only one or two related pages?
- Should left sidebar sections have a fixed order across the site?
- Which right sidebar hooks are worth building first?
