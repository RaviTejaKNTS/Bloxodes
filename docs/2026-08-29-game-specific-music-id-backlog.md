# Game-specific music ID backlog

Checked: 2026-08-29

This is the working inventory for game-specific Roblox Music ID pages. It combines the five pages already configured in Bloxodes, the Brookhaven RP page completed in this task, and the source-backed candidates reviewed for the next batches.

The scope is deliberately narrower than “every Roblox game with a radio.” A game belongs here when it has a distinct music, radio, boombox, speaker, vehicle-radio, or custom-sound control and enough game-specific evidence to make a useful page. A generic Boombox list copied across unrelated games does not count.

## Definition of done for each future page

1. Confirm the current in-game control and whether it accepts a song ID, a sound ID, a built-in list, or a pass-gated radio.
2. Capture a game-specific source with a checked date and enough usable rows. Roblox Music Discovery is useful for associations, but it is not a live playback test.
3. Keep canonical Roblox audio metadata separate from the game association and preserve the source URL, use type, and compatibility status.
4. Write the page in the existing game-specific style: searchable rows, clear copy instructions, practical troubleshooting, a source explanation, and a focused FAQ.
5. Seed managed development, verify the rendered route, metadata, canonical URL, pagination, search, JSON-LD, and sitemap entry before any production release.
