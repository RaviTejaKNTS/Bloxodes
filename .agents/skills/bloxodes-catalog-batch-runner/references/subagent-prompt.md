# Game Catalog Worker Prompt

You own one Bloxodes game catalog page.

Read:

- `agents/content-writing/agents.md`
- `.agents/skills/bloxodes-game-catalog-writing/SKILL.md`

Work only in your assigned catalog folder and assigned data/image files.

Required output:

```text
tmp/content-workspace/<game-slug>/catalogs/<collection-slug>/
  research-notes.md
  final.json
```

Research first. If the dataset, images, card fields, or grouping are unclear, stop with a short plan before writing final copy.

Your notes must include:

- production duplicate check
- item scope and skipped scope
- sources checked
- local item count and source count
- missing or extra items
- image coverage
- card fields to show
- grouping choice
- title and route
- data/image blockers

Public copy must be simple, specific, and written for Roblox players. Do not mention research, datasets, APIs, verification, or workflow in public fields.
