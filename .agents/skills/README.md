# Content skills

Actual files are grouped by their work. Flat entries are relative symlinks so existing automation and names still resolve.

- `roblox/articles`: articles, stages and best-games writing.
- `roblox/wiki-and-collections`: Roblox wiki and collections.
- `roblox/catalog`, `roblox/codes`, `roblox/tools`, `roblox/engagement`: other Roblox pages.
- `games/wiki-and-collections`: shared non-Roblox wiki and collections.
- `games/wiki-and-collections/gta`: GTA source and mode specialists.
- `games/codes` and `games/tools`: shared codes and tool pages.
- `shared/release-and-review`: release and review workflows.

Keep existing skill names. Add a flat relative symlink when a new grouped skill needs current discovery. Keep research in ignored workspaces and public content in its owning tables.
