# Bloxodes Events Research

Use this for one approved events page. Research only. Do not write `final.json`.

Write:

```text
tmp/content-workspace/<game-slug>/events/<game-slug>/brief.md
```

Include:

- existing Bloxodes events page and timeline rows
- exact game identity and universe ID
- event source path
- whether timeline rows come from an approved importer
- evergreen value of the page
- facts to use
- facts to avoid
- open gaps or risks
