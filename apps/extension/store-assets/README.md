# Extension Store Assets

Reusable browser-extension marketing assets live here. Keep the source screenshots unchanged so they can be cropped or composed for future Chrome Web Store, Microsoft Edge Add-ons, website, and social uses.

## Source screenshots

- `screenshots/source/rivals-game-page-active-codes.png` — RIVALS game page with the full active-codes widget, 2132×1616.
- `screenshots/source/rivals-active-codes.png` — focused active-codes widget, 2052×858.
- `screenshots/source/rivals-player-history.png` — focused seven-day player-history widget, 1990×916.
- `screenshots/source/extension-popup-options.png` — signed-in extension popup with both widget toggles enabled, 672×910.

The optimized WebP copies used by the public extension page are in `apps/web/public/browser-extension/`.

## Chrome Web Store screenshots

The `screenshots/chrome-web-store/` files are the 1280×800 JPEGs uploaded with Chrome Web Store version 4.1:

- `01-rivals-game-page.jpg` — full RIVALS game page with the active-codes widget.
- `02-active-codes.jpg` — focused active-codes widget.
- `03-player-history.jpg` — focused seven-day player-history graph.
- `04-popup-options.jpg` — signed-in extension popup and widget toggles.

These are also the preferred store-ready assets for future browser-store updates.
